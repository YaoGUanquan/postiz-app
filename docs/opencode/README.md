# OpenCode Memory Docs

This folder stores project memory and recovery notes for OpenCode sessions.

## Files

- `docs/opencode/project-memory.md`: architecture, conventions, and key paths.
- `docs/opencode/recovery-runbook.md`: quick recovery and resume steps.
- `docs/opencode/session-log.md`: chronological task log for handoff/resume.
- `AGENTS.md`: session startup + update rules for OpenCode.

## Usage

- Start new chat sessions by sharing `docs/opencode/project-memory.md` first.
- If work is interrupted, follow `docs/opencode/recovery-runbook.md`.
- Keep this folder updated when deployment or architecture changes.
